# Ошибка: Зацикливание в длинной задаче (повтор шагов без прогресса)

- **Дата:** 2026-09-20
- **Автор:** Даниил
- **Где:** длинные сессии агента-разработчика (до внедрения протокола ТЗ→блоки→цели→журнал)

## Симптом

В длинных задачах агент повторял одни и те же шаги/блоки без новой информации и без прогресса к цели. Пользователь замечал «топтание на месте», задача не двигалась.

## Причина

В промте не было обязательного протокола для больших задач: не требовалось сначала выдавать краткое ТЗ (цель, вход/выход, ограничения, список блоков с целями), вести журнал задачи и ставить чек-поинты в конце каждого блока. Не было правила анти-зацикливания (3+ одинаковых попытки → стоп, чек-поинт, вопрос пользователю).

## Решение

Внесено в промт v1.1: большая задача по умолчанию → ТЗ → блоки «Часть 1 из N … Часть N из N» → цели → журнал задачи; чек-поинт в конце каждого блока; анти-зацикливание (детекция 3+ одинаковых попыток → остановиться, вывести «сделано X, застрял на Y», спросить). Шаблон 5 добавлен в dev-templates.

## Как предотвратить

- Любую большую задачу начинать с краткого ТЗ и списка блоков с измеримыми целями.
- В конце каждого блока — чек-поинт (что готово / что дальше).
- При 3+ одинаковых попытках без новой информации — немедленная остановка и вопрос пользователю.
