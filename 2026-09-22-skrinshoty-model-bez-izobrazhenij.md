# Ошибка: модель не может прочитать скриншоты — визуальная проверка таблиц через screenshot не работает

- **Дата:** 2026-09-22
- **Автор:** Педагог-методист (комплект opencode-kollegam)
- **Где:** проверка корректности отображения таблиц Word-документа («Лотос»), officecli view screenshot

## Симптом

Для визуальной проверки таблиц выполнен `officecli view <файл> screenshot --grid 2 -o grid.png`. Ожидалась проверка рендера по картинке, но при чтении файла модель ответила: «this model does not support image input». Скриншот бесполезен для агента.

## Причина

Ограничение текущей модели: нет поддержки ввода изображений (vision). Инструмент точно рендерит PNG, но агент физически не может его воспринять; попытка — пустая трата шага.

## Решение

Перешли на текстовые проверки рендера:
- `officecli view <файл> html -o doc.html` + анализ тегов `<table data-path=... style="width:...pt;table-layout:fixed">` — подтверждено, что все таблицы в пределах полосы (467 pt < 482 pt на А4);
- проверка `query tbl` (кол-во строк/колонок, colWidths, границы);
- `officecli validate` + issues (структурные ошибки таблиц = 0).

## Как предотвратить

- При отсутствии vision у модели: использовать HTML-рендер и текстовые проверки (ширины, атрибуты таблиц, validate, issues) вместо скриншотов.
- Скриншоты генерировать только для пользователя (он может посмотреть картинку в Preview), а не для собственного анализа.
- Перед вызовом screenshot-инструментов проверять: «умеет ли текущая модель читать изображения?» Если нет — сразу идти по текстовому пути.
