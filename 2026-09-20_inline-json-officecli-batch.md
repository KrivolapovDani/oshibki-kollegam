# Ошибка: inline-JSON в officecli batch ломался кавычками PowerShell

- **Дата:** 2026-09-20
- **Автор:** Даниил
- **Где:** правка Office-документов (docx/xlsx/pptx) через officecli

## Симптом

При передаче batch-правок Office-документов inline-JSON в командной строке PowerShell ломался кавычками: 2 ошибки подряд до успешного выполнения. Команда не выполнялась или выполнялась неверно.

## Причина

В промте отсутствовало направление «Office-документы» с правилом: batch-правки передавать через JSON-файл + `--input <file>`, а не inline-JSON (inline ломается кавычками PowerShell). Агент не знал ловушку окружения.

## Решение

Добавлено направление 7 «Office-документы» в промт v1.1 и dev-registry: batch-правки — JSON в файл + `--input <file>`; при блокировке файла сначала `close`, затем проверка процессов (POWERPNT/WINWORD/EXCEL); НЕ убивать officecli-процесс (это MCP-сервер).

## Как предотвратить

- Для 3+ правок одного Office-файла использовать batch с JSON-файлом (`--input`), не inline-JSON.
- При блокировке файла: `close` → проверить процессы, держащие файл.
- Никогда не убивать officecli-процесс — это MCP-сервер, инструмент пропадёт до перезапуска opencode.
