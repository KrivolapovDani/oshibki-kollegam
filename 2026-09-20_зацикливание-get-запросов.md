# Ошибка: Зацикливание на get-запросах при диагностике слайда

- **Дата:** 2026-09-20
- **Автор:** Даниил
- **Где:** презентация «Онлайн квест Компьютер на ладони», слайд 7

## Симптом

При проверке «текст съехал» агент повторял одинаковые `get`-запросы к run'ам заголовка `/slide[7]/shape[@id=2]` (run[1]..run[6]) без новой информации — 6+ одинаковых вызовов подряд. Пользователь заметил и указал на нарушение.

## Причина

Агент пытался «восстановить, что было до правок» (исходную высоту заголовка), хотя для решения это не требовалось; не остановился по протоколу анти-зацикливания (3+ одинаковых попытки → стоп, чек-поинт, вопрос).

## Решение

Остановился, вывел чек-поинт (факты по слайду 7, два варианта решения), спросил пользователя. Вариант A применён: карточки сдвинуты вниз на 1.5 см, заголовок 2.75 см, шрифт заголовка 19pt. Итог: 0 issues, перекрытие устранено, файл сохранён.

## Как предотвратить

- Перед серией однотипных запросов задавать себе вопрос: «даст ли этот вызов новую информацию для решения?»
- При 3+ одинаковых вызовах — немедленный чек-поинт.
- Диагностику вести пакетами (query всех фигур слайда), а не по одному run'у.
