# Ошибка: MCP fetch/time не работали — npm-пакеты отозваны; ставить через uv (проверенные ссылки)

- **Дата:** 2026-09-21
- **Автор:** Разработчик-агент opencode (комплект opencode-kollegam)
- **Где:** установка MCP-серверов комплекта (`opencode.jsonc`)

## Симптом

В конфиге комплекта 5 MCP-серверов: memory, sequentialthinking, officecli, fetch, time.
memory/sequentialthinking/officecli заработали, а fetch и time падали
«Connection closed»: файлы `C:\Users\Admin\.local\bin\mcp-server-fetch.exe` и
`mcp-server-time.exe` не установлены, а конфиг ссылается именно на них.

## Причина

Попытка поставить npm-пакеты `@modelcontextprotocol/server-fetch` и
`@modelcontextprotocol/server-time` дала 404 — пакеты **отозваны**:
`mcp-server-fetch` отдан security-заглушке `0.0.1-security`,
`mcp-server-time` — unpublished (2025-05-14). В GitHub-релизах
modelcontextprotocol/servers бинарников нет (assets пустые). На машине не было
Python >=3.10 и uv — серверы невозможно запустить.

## Решение

Официальный источник fetch/time — **Python-пакеты из того же GitHub-проекта**
modelcontextprotocol/servers (в PyPI скрывается под именами mcp-server-fetch,
mcp-server-time). Ставить через uv:

```powershell
# 1. Установить uv (если нет): официальный установщик astral.sh
irm https://astral.sh/uv/install.ps1 | iex   # ставит uv.exe в ~/.local/bin

# 2. Поставить оба сервера (uv сам скачает нужный Python >=3.10)
uv tool install mcp-server-fetch
uv tool install mcp-server-time
# Появятся шимы: C:\Users\Admin\.local\bin\mcp-server-fetch.exe
#                 C:\Users\Admin\.local\bin\mcp-server-time.exe

# 3. В opencode.jsonc включить (пути уже совпадают):
#    fetch/time "enabled": true
```

Результат: `mcp connected server=fetch tools=1`, `server=time tools=2`.
Все 5 MCP комплекта работают (memory 9 tools, sequentialthinking 1,
officecli 1, fetch 1, time 2).

## Проверенные ссылки установки для всех MCP комплекта (Windows)

- **memory** — npm-пакет из GitHub (modelcontextprotocol/servers):
  `cmd /c npx -y @modelcontextprotocol/server-memory`
- **sequentialthinking** — npm-пакет из GitHub:
  `cmd /c npx -y @modelcontextprotocol/server-sequential-thinking`
- **officecli** — прямая ссылка GitHub (НЕ `irm ... | iex` — mirror отдаёт битый файл):
  `https://github.com/iOfficeAI/OfficeCLI/releases/download/v1.0.151/officecli-win-x64.exe`
  (размер ~33 МБ, SHA256 `57cd0e597514a4948ca034ea187637a18ad5b44a6e6729dfb7799414e06a083f`)
- **fetch** — `uv tool install mcp-server-fetch` (PyPI; GitHub: modelcontextprotocol/servers/src/fetch)
- **time** — `uv tool install mcp-server-time` (PyPI; GitHub: modelcontextprotocol/servers/src/time)

## Как предотвратить

1. Скачивать MCP только по проверенным ссылкам выше (для officecli — напрямую
   с GitHub, а не через mirror-установщик).
2. Перед установкой проверять, что пакет не отозван:
   `npm view <пакет> version` — если видите `0.0.1-security` или 404 — пакет
   отозван, ищите другой канал (PyPI/uv) или соберите из исходников.
3. Для Python-MCP (fetch/time) использовать uv: он сам подтянет нужный Python
   и поставит шимы в `~/.local/bin`.
