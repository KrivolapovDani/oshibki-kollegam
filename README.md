# Ошибки коллег — общая база

Общая база ошибок для всех, кто работает с opencode (промты педагога-методиста и разработчика).

## Зачем это

Чтобы каждый не наступал на одни и те же грабли: если кто-то нашёл ошибку и её решение — она попадает сюда, и все остальные видят, как её избежать.

## Как добавить ошибку

1. Скопируйте файл `_ШАБЛОН_ошибки.md`.
2. Переименуйте: `ГГГГ-ММ-ДД_краткое-название.md` (например, `2026-09-20_зацикливание-get-запросов.md`).
3. Заполните все разделы.
4. Сохраните файл в этой папке и отправьте изменения в GitHub (через opencode — он сделает это сам при «самоанализ», или через веб-интерфейс GitHub: кнопка «Add file»).

## Как читать

Откройте любой файл с датой — там: симптом, причина, решение, как предотвратить.
